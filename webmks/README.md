# VMware HTML Console SDK assets

The SDK is not redistributed by this project. Download the VMware HTML Console
SDK from Broadcom under its own license and place these four files in this
directory before deployment:

- `jquery.min.js`
- `jquery-ui.min.js`
- `wmks.min.js`
- `wmks-all.css`

The directory is mounted read-only into the Gateway container.
